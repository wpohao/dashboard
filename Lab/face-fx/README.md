# FaceFX ✨ 手勢變臉

對著鏡頭比手勢，臉就會變成貓、狗、卡通大眼或戴上假面舞會面具；比 🤟 把背景換成極光星空，比 ☝️ 讓指尖噴出 GPU 粒子。

全部在瀏覽器裡跑，影像不會上傳：

- **MediaPipe Tasks Vision**：臉部 478 點＋52 種表情係數、手勢辨識、人像去背
- **WebGPU**：鏡頭濾鏡（卡通描邊、大眼變形、調色、星空去背）＋ 16 萬顆 compute shader 粒子
- **Canvas 2D**：貓耳、狗耳、鬍鬚、面具等造型，貼著臉部座標系畫，會跟著頭轉

## 啟動

雙擊 `start.cmd`，或在這個資料夾執行：

```
py -3 -m http.server 8765
```

再用 Chrome 開 http://localhost:8765/ 。相機只允許在 `localhost` 或 https 下使用，直接雙擊 `index.html` 打不開相機。

不想開相機：按「示範模式」，或開 http://localhost:8765/?demo 。

## 手勢

| 手勢 | 效果 | 鍵盤 |
|---|---|---|
| ✌️ | 🐱 貓咪：貓耳（會抖）、鬍鬚、粉紅鼻；張嘴會「喵～」露虎牙 | 1 |
| 👍 | 🐶 小狗：垂耳（受重力擺動）、黑鼻頭、眼周斑；張嘴吐舌頭 | 2 |
| 🖐 | 🎨 卡通：大眼變形＋色階＋描邊、眼睛高光；張嘴「!!」、笑會飄音符 | 3 |
| ✊ | 🎭 假面舞會：金色面具、水鑽、羽毛、紫色暗角 | 4 |
| 🤟 | 🌌 星空去背（開／關） | B |
| ☝️ | 🪄 指尖噴粒子（比著就噴） | P 切換常駐，可用滑鼠 |
| 👎 | 全部清除 | 0 |

手勢要維持約半秒，手掌上會出現進度環。H 顯示手部骨架、S 拍照存 PNG。

## 網址參數（截圖／除錯用）

`?demo&mode=cat|dog|toon|mask&bg=1&magic=1&skeleton=1`：示範模式固定在指定效果，不跑自動腳本。

## 檔案

- `src/main.js`：啟動、主迴圈、模式切換
- `src/vision.js`：MediaPipe 包裝（臉、手勢、去背）
- `src/gestures.js`：手勢 → 動作，含維持時間判定
- `src/gpu.js`：WebGPU 濾鏡與粒子（WGSL）
- `src/overlays.js`：各種臉部造型
- `src/demo.js`：示範模式的假人與假資料
